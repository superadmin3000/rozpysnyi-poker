# Розписний покер — Online MVP

## Запуск
1. Встановіть Node.js LTS.
2. Відкрийте термінал у цій папці.
3. Виконайте `npm install`.
4. Виконайте `npm start`.
5. Відкрийте один з адресів (сервер друкує їх у консолі):
   - **HTTP:** http://localhost:3000
   - **HTTPS (для мікрофона):** https://localhost:3443

### HTTPS і голосовий чат
Сервер автоматично піднімає **HTTPS** на порту **3443** із self-signed сертифікатом (папка `certs/`).

- На **цьому ПК**: відкрийте `https://localhost:3443` → браузер покаже попередження → **Додатково** → **Перейти на сайт** (це нормально для локального сертифіката).
- **Телефон / інший ПК у Wi‑Fi**: у консолі сервера буде рядок на кшталт `https://192.168.x.x:3443`. Відкрийте його, прийміть сертифікат, увімкніть **🎤 Мікрофон**.
- Або господар кімнати натискає **«🌐 Публічне посилання»** (потрібен `npm install localtunnel`) — отримаєте публічний **https://…loca.lt**.

Без HTTPS браузери блокують мікрофон (окрім `http://localhost`).

## Тест 4 гравців на одному ПК
Створіть кімнату у першій вкладці, скопіюйте код кімнати та відкрийте ще 3 вкладки/вікна. У кожному введіть інше ім’я та код.

Або додайте ботів кнопкою **«+ Додати бота»** (доступна лише творцю кімнати) — можна грати наодинці проти 1–3 ботів.

**Перепідключення:** якщо закрили вкладку або оновили сторінку — гра автоматично відновить сесію (код кімнати + токен у sessionStorage). Достатньо знову відкрити той самий URL.

**Чат:** Голосовий — кнопка «🎤 Мікрофон» (WebRTC; потрібен HTTPS або localhost).

Для гри з інтернету зручніше «Публічне посилання» або власний хостинг.

## Зафіксовані правила
- 37 карт: 36 + джокер.
- Перший здавач визначається відкриттям по одній карті по черзі до першого туза.
- Після роздачі наступна карта визначає козир; якщо це джокер — без козиря.
- Першим ходить гравець наступний після здавача.
- Раунди: 1–9, Темна, Без козиря, Золота ×4, Мізер.
- На Мізері 9 взяток: +100 переможцю, іншим 0.
- Сума всіх замовлень не може дорівнювати кількості взяток у раунді (останній гравець не може зробити таку ставку).
- Не можна замовляти 0 взяток три рази підряд у раундах із торгами (1–9, Темна, Без козиря).
- Підрахунок (1–9, Без козиря, Темна): точно = +10×взятки; 0/0 = +5; перебір = +1×кожна взятка; недобір = −10×(замовлено−взято). На Темній усі очки ×2.
- Джокер можна віддавати за замовлену (ведучу) масть.
- Джокер «постаршій масті»: усі, хто мають цю масть, зобов’язані скинути найстаршу карту масті. Джокер завжди забирає взятку, окрім випадку коли хтось б’є козирем (бо немає масті).
- Джокер «по старших козирях»: джокер завжди забирає взятку.
